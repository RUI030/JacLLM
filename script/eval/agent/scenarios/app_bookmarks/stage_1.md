Build a bookmark manager web app like linkding. A form at the top has three fields in this order: URL, Title, and Tags (comma separated), and a "Save" button. The list below shows each bookmark's title as a link to its URL, and its tags. Clicking a tag opens the page /tags/<tag>, which lists only the bookmarks with that tag and has a link "All bookmarks" back to the full list. Bookmarks are saved on the server. Start with one bookmark: "Jac docs" at https://docs.jaseci.org tagged "docs". Keep styling minimal. Validate in the browser that saving a new bookmark shows it, and that clicking its tag shows only matching bookmarks.
