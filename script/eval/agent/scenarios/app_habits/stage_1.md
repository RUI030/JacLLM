Build a habit tracker web app like Beaver Habits. The home page lists habits, each with a row of seven checkboxes for the last seven days (today on the right) and the current streak as "Streak: N" (consecutive checked days ending today). A text box and an "Add habit" button add a habit. Start with two habits, "Read" and "Exercise", with nothing checked. Check marks are saved on the server. Keep styling minimal. Validate in the browser that checking today for Read shows "Streak: 1" and that it stays after a reload.
