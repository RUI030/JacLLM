Build a poll web app like Rallly or StrawPoll. The home page has a form to create a poll: a Question field and three Option fields, then a "Create poll" button. Creating a poll opens its own page at /polls/<id> showing the question and a "Vote" button next to each option. Each vote is saved on the server and the page shows the vote count next to each option as "N votes" ("1 vote" for one). Keep styling minimal. Validate in the browser that creating a poll opens its page and that voting twice for one option shows "2 votes".
