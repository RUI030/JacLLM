Build a to-do list web app like TodoMVC. One text box at the top: typing a task and pressing Enter adds it to the list. Each task has a checkbox to mark it done and a Delete button. Below the list show how many tasks are not done as "N items left", and three filter links, All, Active and Completed, that change the page address (for example /active) so the filtered view survives a reload. Tasks are saved on the server, so they are still there after reloading the page. Keep styling minimal. Validate in the browser that adding two tasks shows "2 items left", that checking one shows "1 item left", and that the Completed filter shows only the checked task.
