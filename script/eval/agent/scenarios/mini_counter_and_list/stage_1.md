Build a one-page visitor log web app. The page shows the heading "Visitor log", one text box, a button "Sign in", the line "N visitors today", and under it the names that signed in, one row each in the order they signed in. Signing in with a name adds it to the list and raises the number by one. Signing in with an empty box does nothing. Names are saved on the server, so the list and the number are still the same after reloading the page. Keep styling minimal.
