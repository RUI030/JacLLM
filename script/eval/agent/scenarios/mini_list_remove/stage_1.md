Build a one-page chores web app. The page shows the heading "Chores", one text box, a button "Add chore", and under them the chores, one row each in the order they were added, each row with its own button "Remove". When there are none it says "Nothing to do". The box is cleared after adding. Chores are saved on the server, so adding and removing both stay after reloading the page. Keep styling minimal.
