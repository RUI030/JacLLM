Build a one-page pet register web app. The page shows the heading "Pets", two text boxes, the first for the pet's name and the second for its species, a button "Add pet", and a table with the columns "Name" and "Species", one row per pet in the order added. When there are none it says "No pets yet". If either box is empty nothing is added. Both boxes are cleared after adding. Pets are saved on the server, so they are still there after reloading the page. Keep styling minimal. Validate in the browser that adding Rex the dog shows "Rex" and "dog" and that the row stays after a reload.
