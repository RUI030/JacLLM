Build a small recipe web app with a list of a few hard-coded recipes and a page for each recipe. If someone opens an address that does not exist (for example a mistyped page name), the app shows a friendly 'page not found' message with a link back to the recipe list, instead of a blank page. Keep styling minimal. Validate in the browser that a recipe page opens from the list and that a made-up address shows the not-found message.
