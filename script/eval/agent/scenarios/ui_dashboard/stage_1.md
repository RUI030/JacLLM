Build an admin dashboard for a small SaaS called Metrica. It has a sidebar with Overview, Customers and Settings pages. Overview shows four stat cards (MRR, active customers, churn, new signups) and a list of the five most recent signups. Customers is a table of customers (name, email, plan, status) with a search box that filters by name and an "Add customer" button that opens a dialog with name, email and plan; new customers are saved on the server and appear in the table. Settings has a form to change the workspace name, and the new name shows in the sidebar header after saving. Make it look like a real product. Validate in the browser that adding a customer shows it in the table and that saving a new workspace name updates the sidebar.
