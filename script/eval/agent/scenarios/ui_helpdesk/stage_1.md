Build a helpdesk app called Ticketly. The tickets page has tabs for Open, Pending and Closed tickets, each ticket showing its subject, customer and how long ago it was updated, and a "New ticket" button that opens a dialog with subject, customer email and message. Clicking a ticket opens its own page with the conversation thread, a reply box and a select to change the status. Everything is saved on the server. Start with a few example tickets. Clean and calm, like a tool support agents use all day. Validate in the browser that a new ticket appears under Open and that changing a ticket to Closed moves it to the Closed tab.
